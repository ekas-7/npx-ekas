# npx-ekas

`npx-ekas` is a simple, yet powerful, personal CLI card built using Node.js. It serves as a digital business card that you can share quickly via the `npx` command.

---

## Features
- Provides a concise and interactive way to share your professional details.
- Easy to execute with a single command: `npx ekas`.
- Customizable for future enhancements or updates.

---

## Installation

You don’t need to install anything! Simply run the following command:

```bash
npx ekas
```

This command fetches the latest version of the CLI card from npm and displays your information.

---

## Usage

1. Open your terminal.
2. Run the following command:

   ```bash
   npx ekas
   ```
3. View the displayed information, such as your name, contact details, and professional links.

---

## How It Works

1. **Node.js CLI**: The project is built using Node.js to create an interactive CLI.
2. **npx Command**: The `npx` command fetches the package from npm, so there's no need to install it globally.

---

## Project Structure

- **`index.js`**: Contains the core logic for the CLI card.
- **`package.json`**: Defines metadata and dependencies for the project.
